可执行文件

可执行文件 = 描述信息 + 程序

程序：源程序中的汇编指令和定义的数据

描述信息：主要是 masm.exe、link.exe 对源程序中相关伪指令进行处理所得到的信息

end start 指明程序入口，被转化为一个入口地址，存储在可执行文件的描述信息中

段容量

一个段段容量不能大于 64KB ，这是受 8086CPU 的限制

有些 NP-hard problem 在 input data 以 unaray 的形式表达时，可以使用 dynamic programming 在以 input size 为自变量的 polynomial time 解决，此时的 algorithm 被称为是 pseudopolynomial1 的。通过 rounding input value 可以得到一个 polynomial in the input size 的 approximation algorithm.

对于其他 problem, 则通常将 input instance 分为 “large” 和 “small” 两个部分，对 large input 进行 rounding, 然后使用 DP 在 polynomial-time 单独求解得到一个存在 error parameter 的 solution, 再通过一些方式结合 small input 得到最终的 solution.

The bin-packing problem

bin-packing problem 指的是下列问题：

给定 nnn 个大小分别为 a1,a2,…,ana_{1}, a_{2}, \dots, a_{n}a1​,a2​,…,an​ 的 pieces (或 items), 满足

只需令 ai=2bi/Ba_{i}=2b_{i} / Bai​=2bi​/B 并检查能否装进 2 个 bin 即可将 bin-packing problem 转化为 partition problem. 由于 partition problem 是 NP-complete 的，于是有下列 theorem.
